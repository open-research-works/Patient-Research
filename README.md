# Patient Research

Evidenzorientierte, fortlaufend aktualisierte Dossiers zu komplexen medizinischen Fragen.

## Konzept

Die Seite orientiert sich am Nutzen langer, praxisnaher Themenartikel: ein Thema wird über längere Zeit ausgebaut, statt bei jeder neuen Beobachtung einen neuen Kurzbeitrag zu veröffentlichen.

Zusätzlich werden bei Patient Research strikt getrennt:

- objektive Befunde
- wissenschaftliche Evidenz
- plausible Einordnung
- N-of-1-Beobachtungen
- offene Hypothesen
- spätere Korrekturen

Private medizinische Rohdaten bleiben außerhalb dieses öffentlichen Repositories.
